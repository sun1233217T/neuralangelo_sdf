# 定位分析：局部显式 B 样条场 vs 全局神经场

> 目的：梳理本方法（THB 层次 B 样条 NeuS）相对 NeuS / Neuralangelo 类全局神经表示的
> 结构性优势，确定论文故事线与可验证的实验。2026-09-24。

## 0. 核心差异的数学本质

| | 本方法 | NeuS / Neuralangelo |
|---|---|---|
| 场的定义 | SDF(x) = Σ_{i∈N(x)} w_i(x)·c_i | SDF(x) = MLP(x) 或 MLP(hash(x)) |
| 支撑集 | 紧支撑：deg-2 时 \|N(x)\| = 27 个局部系数 | 全局：任意 x 依赖全部网络参数 |
| 参数语义 | 系数即局部几何（位置↔参数一一对应） | 参数无空间语义 |
| 解码器 | 无（直接加权求值） | MLP 解码（hash 方案中 MLP 混合所有特征） |
| 细化 | THB 局部细分 + 精确系数转移（已验证场值连续） | 固定分辨率（NGP）或 coarse-to-fine 调度 |

一句话：**他们的表示是"一个知道整个场景的函数"，我们的是"一堆积木的局部拼接"。**
所有下游优势都从这个差异推出。

## 1. 优势领域（按论文说服力排序）

### 1.1 局部编辑与增量更新——最有分量的卖点
- **机制**：紧支撑 ⇒ 修改某区域的系数在数学上严格不影响支撑域之外的场值。
  MLP 场中任何新数据的梯度都会传遍全网（全局干扰/灾难性遗忘）。
- **已有证据**：我们的 refine（细分）与 prune（剪枝）就是局部结构手术，
  500k 全程稳定——这在全局场上没有对应物。
- **应用场景**：
  - 在线重建 / SLAM：新帧只更新触及的局部系数 + 局部细化，无需防遗忘机制
  - 局部重扫描更新（数字孪生：工厂设备更换后只重建该区域）
  - 交互式编辑：雕塑家改局部，其余部分零漂移
- **可做的验证实验**：训练完成后用新观测微调一个子区域，量化远处场值漂移量，
  与 NeuS baseline 同设置对比（预期：我们漂移≈0，NeuS 显著）。

### 1.2 空间可裁剪性与区域级分发
- **机制**：子树的系数块导出即为独立可求值的子模型（不需要"蒸馏"）。
  配合稀疏存储（只存活跃 cell），天然支持区域级压缩、传输、并行拟合与拼接。
- **应用场景**：大场景分块重建后无缝拼接（B 样条拼接理论成熟）；
  云端大模型 → 边缘端只下载关注区域。
- **可做的验证实验**：从训练好的场中裁出一个子区域独立求值，与整场求值逐点对比
  （预期：紧支撑边界外严格一致，边界内误差=过渡带宽度）。

### 1.3 解析可微性（闭式任意阶导数）
- **机制**：B 样条基函数闭式可导，法向/曲率/eikonal 残差全部解析可得，
  不需要 autodiff 计算图，成本低且数值稳定。我们已有 CUDA 解析反传实现。
- **应用场景**：需要二阶几何量的下游（曲率光顺、可制造性分析、法向一致性约束）；
  训练中曲率正则的边际成本几乎为零。
- **可做的验证实验**：法向/曲率计算的速度与精度对比（解析 vs autodiff vs 数值差分）。

### 1.4 白盒可诊断性
- **机制**：系数即几何 ⇒ 训练过程完全可观察：活跃集分布、残差的空间定位、
  层级覆盖诊断（本项目的整个优化史——ray-level 分析、切片、锚定——都建立在此上）。
- **应用场景**：科研迭代效率；工业场景的质量控制（"哪里没拟合好"可以直接回答）。
- 这一条 NeuS/Neuralangelo 原则上做不到（隐式参数无空间语义）。

### 1.5 与经典几何基础设施的兼容性
- **机制**：层次 B 样条是等几何分析（IGA）、自适应 FEM、CAD（NURBS 同族）的
  成熟工具；转换到网格/细分曲面/仿真有现成理论与软件。
- **应用场景**：重建 → 仿真一体化；CAD 工作流接入。
  神经场要进入这些管线必须先提取 mesh（信息有损且我们的弱项）。

### 1.6 部署友好
- 查询 = 27 次查表 + 加权，无神经网络运行时依赖；延迟确定；可量化/稀疏压缩；
  可上 CPU/嵌入式。神经场部署需要推理框架和（通常）GPU。

### 1.7 空间变化先验的显式注入
- 逐区域调节正则强度（例如弱观测区加强平滑）在我们的框架里是一个局部操作；
  对全局 MLP 而言"只在某区域改变函数性质"没有自然对应物。
- （注：T7 的弱区曲率压平失败是**损失设计**的失败，不是机制不可行的证据。）

## 2. 诚实的劣势（写作时必须主动交代）

1. **高频外观表达弱**：颜色场已被迫退回"特征 + micro-MLP 解码"——纯 B 样条拟合
   视角相关外观不是长处（p1 实验已证明）。
2. **全局低频一致性**需要粗层兜底（L0 存在的理由），参数效率低于端到端 MLP。
3. **存储随分辨率立方增长**：dense index 是已知瓶颈（L5 的 1056³ ≈ 4.7GB），
   THB + 剪枝只是缓解；hash 表在非均匀结构上更省。
4. **训练生态成熟度**：autodiff、初始化、学习率调度等技巧积累远不如 MLP 系。
5. **大形变/动态场景**：紧支撑对拓扑剧变的适应需要频繁结构操作，工程复杂。

## 3. 相关工作坐标（投稿前必须系统检索核实，以下为初步判断）

| 工作 | 与本方法的关系 |
|---|---|
| NeuS / VolSDF / HF-NeuS | 全局 MLP SDF，直接对比对象 |
| Neuralangelo | hash + MLP 解码：存储局部、解码全局；我们无解码器 |
| Instant-NGP | 同上（颜色/密度而非 SDF） |
| Plenoxels / DVGO | 显式体素直接回归：非 SDF、无层次、无紧支撑基函数 |
| TensoRF / K-Planes | 低秩/平面分解：全局耦合，无局部紧支撑 |
| 3DGS 系 | 点基元非连续场：无闭式导数、无内蕴 SDF |
| iMAP / NICE-SLAM 系 | 神经场 SLAM：1.1 节的对比对象而非先例 |
| BeNeRF 等"样条 NeRF" | 样条用于**相机轨迹**（SE(3) 插值），不是场景表示 |
| **待查** | 以（层次）B 样条直接作为 SDF/NeRF 场景表示的先例；IGA 界与图形学界的层次样条重建工作 |

## 4. 论文故事线建议

- **主线 A（推荐）：面向在线/增量重建的显式局部 SDF 场。**
  局部更新 + 动态细化 + 无遗忘 + 解析导数，故事最完整，且契合 SLAM/机器人热点。
- 主线 B：可分析、可编辑、可裁剪的白盒场景表示（数字孪生/工业检测）。
- 主线 C：效率（查询/存储/部署）。只能作辅助卖点，单独撑不起一篇。
- **共同前提**：重建质量与 NeuS 系打平。质量持平之前，A/B/C 都不成立——
  这是当前唯一的关键路径。
